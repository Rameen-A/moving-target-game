This project is a console-based arcade game built in C#. The player
controls an X character using arrow keys and must catch moving targets
before the timer ends. As the player scores points, the targets move
faster, increasing the difficulty and creating a more challenging
experience.
One of the biggest challenges was handling multiple moving targets at
the same time while keeping the game responsive. I also learned how to
manage collision detection, timers, keyboard input, and game loops
inside a console application.
